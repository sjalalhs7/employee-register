MSM LONGROLL ANDROID APK PROJECT
================================

1. Deploy the final web package first.
2. Copy the HTTPS Firebase Hosting URL.
3. Open app/src/main/java/com/msm/longroll/MainActivity.java.
4. Replace:
   https://REPLACE-WITH-FIREBASE-HOSTING-URL
   with your real HTTPS Hosting URL.
5. Open this project in Android Studio.
6. Build > Generate App Bundle / APK > Generate APK.

The app opens the production website in a Custom Tab so Google sign-in works in a real browser context rather than an embedded WebView.

This project is source-ready; a signed APK is not claimed as compiled here because signing/build credentials belong to the company owner.
