# 3D Chase Lab — Final Test Prototype

Open `index.html` in a modern browser.

## Intended AI-builder workflow
This is a portable prototype specification for Canva, Claude, Lovable, Gemini, Meta AI and similar builders.

## Character replacement
The current CSS characters are only a functional visual fallback. For the final production version, replace them with licensed/original GLB/GLTF 3D character models using Three.js, Babylon.js, Spline, or the target builder's supported 3D component system.

## Required final behavior
- Real animated 3D characters
- Idle / run / chase / reaction animations
- Scroll choreography
- Hover/click/touch reactions
- Responsive mobile/desktop
- Blue, green, purple, red and brown palette
- Reduced-motion accessibility
- Performance optimization
