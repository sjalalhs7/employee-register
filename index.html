Complete User Guide: This page explains the access pattern for the Parent/Admin and for all other authorized users. Everyone uses the same website link; access is controlled by the Gmail account that signs in.
01Parent / Admin User
  1. Open the website link: https://sjalalhs7.github.io/employee-register/
  2. Sign in with the authorized Parent Gmail that was created in Firestore as role = parent.
  3. The Parent can see the complete register, including all clients, departments and sectors.
  4. Open Admin: Access to add or remove authorized user Gmail accounts.
  5. For each user, assign the exact Client / Project name that should be used for that user's records.
  6. The Parent account is protected and cannot be removed from the website.
02Department / Sector / Client User
  1. The Parent first adds the user's Gmail in Admin: Access.
  2. The user then opens the same website link: https://sjalalhs7.github.io/employee-register/
  3. The user signs in with the same Gmail address that the Parent authorized.
  4. The system automatically identifies the user's assigned Client / Project and, when assigned, Sector.
  5. The user can add and manage only records belonging to that assigned Client / Project.
  6. The user cannot change their Client / Project to access another client's data.
  7. If the Gmail has not been authorized, access is denied until the Parent adds it.
03Website Access Pattern

There is only one main website URL. There is no separate website URL required for every department, sector or client.

https://sjalalhs7.github.io/employee-register/

Access is controlled by Google Sign-In + authorized Gmail + assigned Client / Project. Employee records, Regions, Sectors, Audit Logs, Recycle Bin and Company Settings are stored in the shared Firebase Firestore database — not in browser memory — so authorized sessions share the same cloud data.

04Daily Data Entry & Printing
  1. Open New Entry and enter the employee information.
  2. Upload the employee photo.
  3. Use Adjust Photo for manual crop/zoom/position, or Auto Fit for automatic passport-box fitting.
  4. Save the employee to the Long Roll.
  5. Use Register (Long Roll) to search, edit or print an existing employee.
  6. Print generates the enrollment pages and the uploaded Police Verification document when available.
05Important Security Rules
  • Never share the Parent/Admin Gmail account.
  • Each department / sector / client should use its own authorized Gmail.
  • Do not manually edit the Client / Project field to another client's name when logged in as a client user.
  • If a user's access must be stopped, the Parent removes that Gmail from Admin: Access.
  • The database remains protected by Firebase Firestore security rules in addition to the website interface.
